FieldWorks

An open, MCP-native industrial AI framework. Protocol-first, multi-agent, designed to run fully on-premises in air-gapped environments.

The problem

The barrier isn't connectivity. The data is accessible. The barrier is fluency. You need to know which tag to query, which historian to open, which dashboard to read. You need to know the plant.

FieldWorks removes that barrier — not by replacing the systems that already work, but by putting a natural language interface on top of them. The same way a web browser didn't replace the control system but made its value accessible to anyone with a network connection, FieldWorks makes plant intelligence accessible to anyone who can ask a question.

The interface is a chat window. The intelligence is the plant.

Three layers
01
Protocol
Conformant MCP servers — one per industrial protocol. MQTT, OPC-UA, Modbus, DNP3, EtherNet/IP, AVEVA. The AI never knows what protocol is underneath. Swap the adapter, nothing else changes.
02
Plant
One topology.yaml describes the facility. Equipment types, instances, attributes, fault modes, write permissions. Change the config, change the plant. The framework code does not change.
03
Agent
Where reasoning happens. Cascade orchestrates. Specialists diagnose. Deadband validates. Millwright executes. Every step logged to an append-only audit trail.
The agents
Cascade
Orchestrates. Receives queries, loads plant context from topology.yaml, dispatches specialists, synthesizes findings. Never touches raw data directly. Knows the plant as a whole.
Specialist
Diagnoses. One per process area — intake, treatment, distribution. Defined by configuration, not hardcoded. Knows their process area in depth.
Deadband
Validates. Noise or signal? Checks duration, trend direction, and confidence threshold against raw data before anything moves to the action path.
Millwright
Executes. Write access only, operator approval required. Ramps instead of steps. Confirms outcome. Documents everything. Called when things get serious.
What it isn't
A cloud service
A proprietary platform
A replacement for your control system
A point solution for a specific vendor or protocol
Autonomous — the operator is always in the loop until they decide, consciously and deliberately, to widen it
